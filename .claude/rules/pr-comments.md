## Pull request comments

- Agents may add comments to this repo's pull requests (AH-Merii/nvim-config) without asking first, e.g. review
  findings, test results, screenshots or answers to review threads.
- Use `gh pr comment`, or `gh api` for inline review comments.
- This covers comments only. Pushing, opening, editing, approving, merging or closing pull requests still needs
  the user to ask.
- Comments follow the global claims-need-sources rule: each claim carries its source.
